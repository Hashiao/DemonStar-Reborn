# 高清素材来源 / HD art provenance

All final images were generated with the built-in image_gen tool, using locally decoded original DemonStar sprites/backgrounds as visual references. Source reference bitmaps remain in ignored `.local/reference/`. No original bitmap files are redistributed. Mechanical atlas slicing and platform icon sizing do not alter the generated artwork.

The original game and underlying designs belong to their respective rights holders. These generated images are outside the MIT code grant; see THIRD_PARTY_NOTICES.md. This is an unofficial fan remake.
