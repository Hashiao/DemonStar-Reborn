# 地面炮门重绘 / Ground-shutter redraws

使用内置 imagegen，以本地原作 32 帧为参考生成两张透明 PNG。生成结果原字节复制入项目，不用代码修改像素。参考帧仅位于忽略的 `.local/m224-*-reference.png`；原图不发布。

Built-in imagegen used 32 local original poses to generate two transparent PNGs. Generated bytes are copied unchanged; no code edits pixels. Source references remain in ignored `.local/m224-*-reference.png` files and are not published.

- [ground-covers-hd.png](../web/assets/ground-covers-hd.png)：6 列×2 行，上排 G_TNK2A，下排 G_TNK3A，均从闭合到开启。 / Six columns by two rows, G_TNK2A above G_TNK3A, closed to open.
- [ground-shutters-hd.png](../web/assets/ground-shutters-hd.png)：6 列×4 行，共 20 帧，最后一行两帧；G_BTANK1A 三列炮门轮换。 / Six columns by four rows, twenty frames with two on the last row; alternating G_BTANK1A shutters.

尺寸和 SHA-256 在 `web/js/campaign-art.js` 的 assets 项；逐帧 crop/offset/visible 由 `tools/import-ground-animations.py` 从生成透明边界和原作帧几何重建。已有主图集生成器调用同一函数，普通构建不需要原作或 Python。 / Dimensions/hashes are recorded in campaign-art.js. The importer derives crops from generated alpha and display offsets/sizes from original frame geometry. The campaign importer calls the same function; ordinary builds require neither the original game nor Python.

实际查看了原始 32 帧、两张最终生成图，以及游戏内闭合/开启画面。每一帧均有透明背景和可见内容；高清纹理、孔位内纹和转门中间姿态是重绘近似，不宣称逐像素还原。轮换炮门的前两次候选有背景残留，未发布，重新生成透明版本。 / All original poses, final atlases and in-game closed/open renders were inspected. Each frame has visible content and transparency. Textures, port interiors and intermediate rotary poses remain redraw approximations, not pixel-identical fidelity. Two rotary candidates with residual backgrounds were rejected and never published.

## 开合盖最终提示词 / Final cover prompt

Use case: stylized-concept. Asset: production top-down DemonStar game sprite atlas. Create exactly 12 sprites in a regular SIX-COLUMN TWO-ROW transparent grid. Reference images are ORIGINAL GAME REFERENCES only; redraw their machines faithfully in high-resolution crisp hand-painted pixel-art style, copper-brown armor and dark charcoal tracks, restrained metallic highlights. Top row: the six G_TNK2A poses from reference 1 in exact order, CLOSED to OPEN. Bottom row: the six G_TNK3A poses from reference 2 in exact order, CLOSED to OPEN. Preserve all details of their silhouettes: top machine short/wide twin brown covers with small silver lower-right cone and black outer tracks; opening exposes exactly two columns of three circular ports. Bottom machine taller with upper armored cabin and lower paired gray door panels opening outward, exposing two columns of three double-bore ports. Copy the six opening stages faithfully, not six closed machines. Within EACH ROW every sprite must have exactly the same base, track position, size, camera, center, colors, lighting and scale; only the door position and exposed ports change. Orthographic view from directly above, orientation exactly as references, no perspective. Equal-size cells with generous transparent margins; sprites centered at identical local coordinates in each cell, top row shorter machine and bottom row taller machine. Reference labels/background must NOT appear. No text, numbers, arrows, labels, grid lines, scenery, floor, shadow, glow, firing, projectiles, explosions or extra pieces. Real transparent alpha. A single 6 by 2 animation atlas.

## 轮换炮门最终提示词 / Final rotary prompt

Create a NEW clean sprite sheet on TRANSPARENT BACKGROUND, matching the true transparent cutout style of image 2. Image 1 provides the machine and 20 animation poses. Image 2 is ONLY a transparency and crisp pixel-art style reference, do not include its machines. Draw exactly twenty copper-brown wide tracked machines in 6 columns x 4 rows, last row contains 2 machines at left. Each machine matches the corresponding numbered pose 0-19 of image 1: its three vertical shutters rotate to expose the left, then middle, then right pair of gun ports, then return to left. Draw clean hard-edged isolated sprites only, all identical size and locked base position. NO GROUND PLANE, NO BROWN HAZE, NO DROP SHADOW, NO GLOW, NO DARK RECTANGLES. Every pixel outside the actual metal silhouettes must be invisible alpha 0. Interior metal opaque. Exact top-down view, copper body, black tracks, gray shutters. No text, labels, cell borders or grid. Preserve source silhouette and orientation. Each sprite centered inside an equal cell with wide EMPTY transparent gutters. This is a game sprite atlas, not a presentation board.
