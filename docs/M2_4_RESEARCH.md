## 撞击与敌弹分别处理

0x4100ff–0x41013e 按原始敌机宽度选撞击伤害：≤16 为 4，17–32 为 12，>32 为 16。0x4266a0 检查碰撞与保护状态后直接调用 0x426530 扣能量；此链路不读取难度变量 0x43ca9c，也不经过敌弹难度分支。有效撞击同时在 0x41014a 对敌机扣 305 HP。护盾可保护主机，但接触仍伤及敌人；重生保护期间不接受该碰撞。原作仍有特殊地图交互分支，不以普通撞击规则替代传送等行为。

敌弹走另一函数 0x426820。0x42683f–0x426879 明确按难度变化：容易为 max(1, floor(基础值/2))，一般为基础值，较难为基础值+1，疯狂为基础值+2。基础值来自原弹体模板 0x5ce320 + 类型×72 + 20，已保存在 player-rules.js 的 damage 表，不是按类型大小粗分成 1/2 点。

四档分别验收，不把敌弹公式擅自应用到撞机。原版难度还影响特定放置记录/补给等，不能以本表宣称整套难度机制已经完全还原。现有射击冷却难度倍率未在本轮重标定。

## 普通中弹无额外无敌；临界能量降火

0x42657f 直接扣能量，随后播放受伤声/效果，不设置普通受伤无敌计时。现移除旧版每次受伤新增的 0.65 秒保护；连续子弹和激光可连续造成命中。掉命后的 45 步复活等待与 135 步保护仍保留；已有入场、炸弹、护盾保护与普通中弹区分。

0x4265aa 检查 0<剩余能量<4：黄、蓝、红的增强等级大于最低档时减 1，因此满级 6→5 只在有效受伤后剩 1–3 能量时发生；继续受伤但存活可继续降级，最低档不退回默认双发。降到零能量则进入原有掉命/掉球/重置流程。此分支对磁力槽存在与前三色不同的写入，未擅自扩展为磁力也同样降级。

## 三项美术定位

- 圈中是定义 ID 47 的 S_ENEMY1A，原图 34×46，A–F 六帧。此前 renderer 将它映射到另一资源 S_ENEMY1（29×31）的高清图。ID 0 使用同一原型但原表没有动画，应固定首帧；ID 47 的原动画初始等待 60、帧间隔 1、六帧往返、两端各停 5、循环计数 5，按定义分别运行。
- 网架炮台为 ID 115 / S_ASTSHT1B，31×34、HP600、速度1、标志0x20400。其名称未匹配机型分支，被通用数字兜底映射为 S_ENEMY2 红色飞机。原资源同名连续保存 32 个方向，另有一张残骸图；32 向选择来自 0x40f150。现使用专用高清方向帧，随背景同速滚动，炮口转向主机。
- 大岩石为 ID61 / S_ASTER1A，原画布40×56，主体约31×49，24帧翻滚中会缩短至约31×32。此前把已经偏长的图放在方格里再拉成40:56，实际主体约21×51。现按每帧原始可见边界和锚点独立绘制，恢复饱满轮廓；初始等待6、帧间隔1、24帧循环999（持续），不以平面旋转代替翻滚。
