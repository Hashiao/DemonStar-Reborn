# v0.2.3 · M2.3 流星轨迹与首关攻击修复

- 默认开启背景音乐：新安装及旧存档升级后生效；之后手动关闭仍正常保存。
- 冲刺流星在结束入场路径时锁定一次玩家位置，之后沿直线飞行，修复持续转弯追踪。
- 第一关 Boss 使用较大的红橙色四芒星、两轮双侧导弹，以及共三轮、每轮五次的蓝色贯穿激光；激光随后停止，星弹继续。
- Boss 前的陀螺恢复横向旋转的六帧动画，沿原路径从速度 2 逐步加速至 12 俯冲。
- 所有 HP 和伤害数值保持冻结。原作证据见 docs/M2_3_RESEARCH.md，高清图集及完整内置 imagegen 提示词见 docs/ART_ENEMY_ATTACKS.md。

Android 最低 Android 10 / API 29，使用本项目独立签名；iOS 最低部署目标 12.0，IPA 为 iPhoneOS ARM64 **unsigned**，需自行签名后安装。最低系统与真机未实测。IPA 外部名称为纯 ASCII 的 DemonStar.ipa。

本版没有声称完成原机录像逐帧对照，其他 Boss 特殊弹型、部件机制、伤害和墙钟速度仍待核对；原版 1–18 关优先，未加入 19–25 新关卡。
