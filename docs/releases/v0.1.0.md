# M1：中文可玩复刻基础

首个中文里程碑，面向 Android 10+ / iOS 12+。本版是开发中的可玩复刻基础，**不是已验收的完整 1:1 原版移植**。

## 本次交付

- Android：本项目独立签名的 `DemonStar-Reborn-release.apk`。
- iPhone / iPad：真正 ARM64 iPhoneOS 构建的 `DemonStar-Reborn-iOS-unsigned.ipa`，**必须自行签名后安装**，不是 TestFlight 版本。
- 源码、安装包 SHA-256 和机器可读验收记录随本次发布提供。

## 已实现

- 导入原作 18 关的 8,368 条地图放置记录与 387 条对象定义，按稳定 ID 重绑定旧地图索引。
- 原始对象血量、速度字段、分值、路径、炮位配置参与游戏运行；18 关 Boss 均有独立定义。
- imagegen 参考原作重绘机库菜单、红/蓝主机、18 位 Boss、18 关背景、第一关主要敌机/地物及武器弹体。
- 中文菜单、状态栏、结算、操作提示和无障碍说明；“轻触屏幕以开始游戏”可实际触发开始。
- 触屏相对移动、自动开火、超级武器、武器升级、导弹、补给、暂停和后台暂停。
- 根据原作短音效的时长、频谱和衰减重建合成音效；没有复制原始音乐或 PCM。

## 验证

- 9 项引擎与原数据回归：18 关地图、对象参数、炮位、碰撞、武器、生命、炸弹、暂停、18 位 Boss 生成与结算。
- 桌面、手机尺寸和旧 WebKit API 回退浏览器交互检查。
- Android Debug / 独立签名 Release 构建、两种 Lint；API 37 / Android 17 的现成只读 AVD 上验证安装、中文菜单、画面推进、拖动、炸弹消耗、暂停、原生返回与后台暂停。
- macOS 使用现成 Xcode 构建，检查 IPA 和主程序最低 iOS 12.0；iOS 18.5 的 iPhone 16 Pro、iPad Pro 模拟器运行打包后的 WKWebView。

部署目标与实际测试版本不同：Android 10 / iOS 12 的旧系统实机仍待验收。没有把 Chromium 中的接口回退测试当作 iOS 12 实测。

## 还原边界

全局计时、难度倍率、玩家伤害、掉落编号、部分运动/碰撞细节与特殊弹型仍有推断；Boss 变形、部件损坏、隐身等尚未逐项还原。未覆盖的敌机/地物仍使用近似图形。原作双人、局域网、地图编辑器、完整断点续关和原版音乐尚未实现。音效尚未通过听觉对照验收。

详情：[还原状态](https://github.com/Hashiao/DemonStar-Reborn/blob/main/docs/FIDELITY.md)。先校准原版 1–18 关，再开发 19–25 关；英文语言包留待后续里程碑。
