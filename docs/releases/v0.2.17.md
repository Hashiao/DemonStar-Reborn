# M2.17 四难度波次与出场位置 / Difficulty-aware waves and spawn positions

按本地 DemonStar 4.04 程序和十八关逐对象清单恢复波次。单人不会再无条件生成双人/高难度的额外补给与敌机；左右位置遵循每条原始记录，不按对称关系删半，也不随机保留一侧。

Restore waves from the local DemonStar 4.04 program and per-placement eighteen-stage ledger. Solo play no longer unconditionally spawns extra multiplayer/high-difficulty supplies and enemies. Each original placement determines its side; there is no symmetry halving or random side selection.

- 原始相邻编队同批生成，保留成员纵向偏移；恢复地物、侧面与斜向入场、持续下移补给及 mode 10 首路径目标。
  Dispatch adjacent formations together with member offsets; restore scenery, side/diagonal entry, moving supplies and mode-10 first path targets.
- Boss 出场后继续调度后续地图记录，避免遗漏地面目标和地物。
  Continue dispatching trailing ground/scenery records after boss creation.
- 游戏中仍可随时暂停调整难度。每批出场读取当前难度与有效人数：已经出现的对象保留，跳过的过去波次不补刷；联机由房主统一生效。
  Difficulty remains changeable while paused. Each batch reads current difficulty/active players; existing objects remain and skipped past waves are not replayed. The LAN host controls the shared setting.
- 关卡档格式保持兼容，读档恢复入口状态并重建调度。房间版本升至 4，联机双方须更新；玩法仍限单人/双人，3P/4P 仅协议预留。
  Keep checkpoint compatibility and rebuild dispatch when restoring stage-entry state. Room revision 4 requires both peers to update. Public play remains solo/two-player, with P3/P4 protocol-only.
- 原始地图、HP/伤害、经典 HUD、18 枚炸弹扩展、三色保留和两端音频实现保持原样。自动补给归属序列与跨关补充另待后续。
  Preserve source maps, HP/damage, classic HUD, eighteen-bomb capacity, color retention and platform audio implementations. Supply ownership/sequences and stage replenishment remain later work.

## 验证与边界 / Verification and limits

356 项引擎/单元测试、25 组浏览器检查通过，包含 144 个关卡/难度/人数逐条清单组合、四档难度全部 12 种切换方向及联机下一批出场验证。Android Release/Debug、Lint（各 0 错误、12 条警告）、API 37 原生操作/设置/三语/双 App LAN 通过。[iOS CI](https://github.com/Hashiao/DemonStar-Reborn/actions/runs/38135345464) 通过 iPhoneOS 构建、iPhone/iPad 模拟器功能/三语/音频、原生双端 LAN 和系统长按检查。

356 engine/unit tests and 25 browser suites passed, including 144 stage/difficulty/player ledger cases, all twelve directed difficulty transitions and subsequent LAN spawning. Android Release/Debug, Lint (0 errors and 12 warnings each), API 37 native controls/settings/localization/two-app LAN passed. [iOS CI](https://github.com/Hashiao/DemonStar-Reborn/actions/runs/38135345464) passed iPhoneOS compilation, iPhone/iPad simulator functionality/localization/audio, native-pair LAN and system long presses.

不宣称逐帧原机时钟一致、完整动画或碰撞 1:1。真实热点、Android–iOS 双真机、最低系统硬件和用户 iPhone 18 Pro/iOS 27.0.1 音频听感仍未验收。Android 使用项目独立签名；IPA 为 unsigned，须自行签名，不可直接安装。

Exact native frame timing and complete animation/collision fidelity are not claimed. Physical hotspots, Android–iOS hardware pairs, minimum-OS hardware and the user's iPhone 18 Pro/iOS 27.0.1 listening quality remain unverified. Android uses the project's own signing key; the unsigned IPA requires user signing and is not directly installable.
