# v0.2.13 — 快速开局、三色进度与切换开火 / Quick setup, color banks and toggle fire

单人开局改为同屏配置：关卡选择明确分为“从头开始”和“选择关卡”，难度、三色保留规则及读档也在这一页。双人共用相同流程。开启三色保留后，下方常驻显示每位玩家黄/蓝/红各六级进度及当前武器标识，沿用原作像素图标与条格表达，保留生命、炸弹和能量 HUD。

新玩家和已有玩家统一初始化为浮动摇杆，覆盖旧固定/八方向偏好，保留按键映射与外设分配。之后仍可手动选择操作方式并保存。默认开火方式为“切换”：按一次持续射击，再按一次停止，整个 A 键持续显示按下状态；触屏、键盘、鼠标、手柄统一支持，双人分别设置。

普通暂停后保持开火。死亡只清除对应玩家；进入下一关、读档和新游戏均需要重新激活。暂停时改为按住开火会清除旧状态，没有按住就停止；改回切换开火也保持关闭，等待重新点击。联机客机修改模式后立即向房主发送停止状态。模式偏好会保存，正在射击的临时状态不会写进存档。

Single player now opens one setup page: clearly choose Start from stage 1 or Choose stage, adjust difficulty and the retained-color rule, or load a save. Two-player modes share the page. With retained colors enabled, each player's yellow/blue/red six-level banks and equipped marker remain visible below the battlefield, using classic pixel icons and segments while preserving the life/bomb/energy HUD.

Fresh and existing players initialize to floating sticks, replacing old fixed/eight-way preferences while preserving bindings and device assignments. Later manual control choices remain persistent. Toggle fire is the default mode: one press keeps firing, another stops, and the whole A button stays visually pressed. Touch, keyboard, mouse and gamepad support it independently per player.

Ordinary pause preserves firing. Death clears only its owner; a new stage, load or new game requires reactivation. Changing to hold mode while paused clears stale fire and stops if nothing is held. Changing back to toggle also stays off until pressed again. LAN clients immediately send a stopped state when changing mode. Mode preferences are saved; transient firing is not stored in checkpoints.
