# M2.11 · iOS 长按修复与游戏模式入口 / iOS touch fix and game-mode menu

版本 / Version 0.2.11（13）。Android 10/API 29+、iOS 12+ 为部署目标。

- 修复 iOS 长按 A、B 和摇杆时的选字/长按菜单冲突。真实触控防护覆盖两位玩家及固定、浮动、八方向操作；联机地址/房间码输入框保留选择与粘贴。
- 主菜单前三项调整为“单人游戏 → 多人游戏 → 设置”。多人游戏中选择“同屏双人”或“局域网双人”；设置不再承担进入联机或切换人数的职责，分玩家改键仍保留。
- 单人入口固定为 1P，不沿用旧的双人模式；取消点击菜单空白处直接开局，键盘 Enter 激活当前聚焦按钮。当前实际玩法仍限两人，3P/4P 仅协议预留。
- 保留已确认的红 P1／蓝 P2、原作 HUD、关卡档案和原生 BGM；本次不调整战斗数值与原作数据。

168 项引擎/单元、六组相关浏览器回归、Android 构建/Lint/API 37 模拟器，以及 iPhoneOS 构建、iPhone/iPad 常规与原生联机检查均通过；XCTest 系统长按检查覆盖两种设备的单人和双人。原生 iOS 检查新增 XCTest 系统长按，区别于 DOM 事件注入；模拟器不代替用户真机复测。

APK 使用本项目独立签名；`DemonStar.ipa` 未签名，需自行签名后安装。保留旧版发布，附 SHA-256 和完整验证报告。

- Fix iOS text selection/callout conflicts while holding A, B or a stick. Native-touch guards cover both players and all three touch styles; LAN address/code fields retain selection and paste.
- The first main entries are Single player → Multiplayer → Settings. Multiplayer offers same-device two-player or LAN play. Settings retain per-player bindings without initiating LAN or choosing player count.
- Single player explicitly starts P1, independent of previous two-player preferences. Empty menu space no longer starts play, and Enter activates the focused option. Public modes still cap at two; P3/P4 remain protocol reserves.
- Preserve red P1/blue P2, the classic HUD, stage checkpoints and native BGM. Combat numbers and original data are unchanged.

168 engine/unit checks, six affected browser suites, Android build/Lint/API 37 checks, iPhoneOS compilation and standard/native LAN iPhone/iPad checks passed. XCTest system long presses passed in solo/two-player modes on both device families. New iOS XCTest system long presses supplement DOM-injected checks; simulator results do not replace the user's physical-device retest.

The APK uses this project's independent signing key. `DemonStar.ipa` is unsigned and requires user signing before installation. Previous releases are preserved; SHA-256 checksums and a full verification report accompany this patch.
