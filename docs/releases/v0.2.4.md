# v0.2.4 · M2.4 受伤规则与第一关机型修复

- 敌弹伤害使用原作弹型表，四档难度分别为减半取整（最低1）、原值、加1、加2。首关星弹为6/12/13/14，激光每次有效命中为2/4/5/6。
- 普通撞机按原机体宽度扣4/12/16，并使被撞敌机损失305HP；原作该分支独立于敌弹难度公式。
- 普通中弹没有额外短暂无敌，保留死亡重生保护。黄、蓝、红武器受伤后剩1–3能量时减一级，包括6→5；死亡则按原规则掉球和重置。
- 修正圈中敌机 S_ENEMY1A 的六帧原型、网架固定炮台的32向图像、大岩石的宽度与24帧翻滚。
- 敌机基础HP、我方武器伤害表、超级武器旧预算均未调整；证据和待核对项见 docs/M2_4_RESEARCH.md。

Android 最低 Android 10 / API29，使用本项目独立签名；iOS 最低部署目标12.0，提供 iPhoneOS ARM64 **unsigned** IPA，需自行签名后安装，文件名 DemonStar.ipa。最低系统和真机未实测。未宣称原机录像逐帧对照或碰撞逐像素一致。

新图集用内置 imagegen 参考本地原作重绘，完整提示词见 docs/ART_M2_4.md。原始图片、EXE、GLB 与用户原始 audio/ 不进入提交。
