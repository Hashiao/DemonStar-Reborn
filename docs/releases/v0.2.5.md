# v0.2.5 · 母舰出击、命中火花与关末奖励

- 补上机械舱门关闭/开启和母舰甲板出击；母舰离场后才开始战斗与无线电播报，支持出击期间暂停、后台恢复和换关重播。
- 放大左下炸弹图标与能量条，去掉图集留白；手机竖横屏仍保持可读。
- 普通敌机击毁恢复逐帧火球、碎火和灰烬；Boss 最终爆炸播完后再打开结算。
- 默认双发与黄色弹体裁切更实，不再把整格透明留白一起缩小。蓝红强化弹按原弹型出现大命中火花；黄色维持小火花。
- 带原作指定标记的地面目标留下焦黑残骸，随场景滚动，不能重复打分或掉落。
- 补齐关末炸弹 ×1000、勋章 ×2000 及合计奖励，防止重复入账；死亡/换关清零勋章。

保留 v0.2.4 的难度伤害、连续中弹、低能量降火、正确首关敌机、固定炮台和岩石动画。敌机基础 HP、我方伤害表及超级武器旧预算未改。

母舰采用本地 4.04 的灰色 88 原型；爆炸关键帧、舱门时长与八类残骸仍是高清重制近似，尚非完整逐帧 1:1。详见 [本轮证据](https://github.com/Hashiao/DemonStar-Reborn/blob/main/docs/M2_5_RESEARCH.md) 和 [imagegen 来源/提示词](https://github.com/Hashiao/DemonStar-Reborn/blob/main/docs/ART_M2_5.md)。

Android 最低部署目标 10 / API29。iOS 最低部署目标 12.0；`DemonStar.ipa` 是 **unsigned** 设备包，需要自行签名，不能直接安装。最低系统和真机尚未实测。两个安装包、SHA256SUMS.txt 和 verification.json 同批交付。

## 本版验收

M2.5 的 80 项引擎/声音回归与六组浏览器检查通过，覆盖出击冻结/恢复、广播时序、命中与击毁特效、底栏五种尺寸、残骸、原作奖励及 M2.4 伤害规则。Android Debug/签名 Release、Lint（0 错误、3 提示）及现有 Android 17 / API37 AVD 出击、摇杆/A/B、旋转、后台和设置检查通过。[iOS CI](https://github.com/Hashiao/DemonStar-Reborn/actions/runs/37989366559) 通过 iPhoneOS ARM64 编译和 iOS 18.5 的 iPhone 16 Pro、iPad Pro 11-inch (M4) WKWebView 检查，包括实际经过出击阶段、新图集加载、移动/开火和 BGM 播放。两包版本 0.2.5（7），全部游戏脚本、图集和音频内容核验一致；HTML/CSS 仅有平台换行差异，包内路径 ASCII。[完整验收记录](https://github.com/Hashiao/DemonStar-Reborn/releases/download/v0.2.5/verification.json)。
